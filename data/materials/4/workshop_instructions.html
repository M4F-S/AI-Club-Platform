2. Get OpenRouter API Key & Configure .env

Explanation: To communicate with an AI model, we need an API Key. We use OpenRouter because it provides access to many models (including free ones) through a unified API. We store this key in a hidden .env file so it is safely loaded into our program without being hardcoded into our scripts.

Go to openrouter.ai -> Settings -> Keys -> Create Key. Create your .env file in the agent-workshop folder:

macOS / Linux:

echo "OPENROUTER_API_KEY=sk-or-v1-your-key-here" > .env

Windows:

Set-Content -Path .env -Value "OPENROUTER_API_KEY=sk-or-v1-your-key-here"

Part 2: The Agent Code (agent.py)

Explanation: This is the core logic of our AI Agent. We define custom tools (Python functions annotated with @tool) that the LLM can use to perform actions. We then create a LangGraph agent that uses a "ReAct" (Reasoning + Acting) loop: it thinks about what to do, calls a tool, observes the result, and loops until it answers the user.

Create agent.py in your folder and paste the complete implementation:

import os
import sys
from dotenv import load_dotenv
from langchain_core.tools import tool
from langchain_openai import ChatOpenAI
from langgraph.checkpoint.memory import MemorySaver
from langgraph.prebuilt import create_react_agent

# 1. Load API Key
load_dotenv()
api_key = os.environ.get("OPENROUTER_API_KEY")
if not api_key:
    sys.exit("❌ Error: OPENROUTER_API_KEY is not set in your .env file.")

# 2. Define Deterministic Tools
@tool
def calculate(expression: str) -> str:
    """Safely evaluates basic arithmetic expressions like '42 * 1024' or '(100 - 25) / 5'."""
    try:
        allowed = set("0123456789+-*/(). %")
        if not set(expression).issubset(allowed):
            return "Error: Expression contains forbidden characters."
        return str(eval(expression, {"__builtins__": None}, {}))
    except Exception as e:
        return f"Calculation error: {e}"

@tool
def get_system_info() -> str:
    """Returns local operating system details and active directory path."""
    import platform
    return f"OS: {platform.system()} {platform.release()}, Current Path: {os.getcwd()}"

# Register available tools
tools = [calculate, get_system_info]

# 3. Configure Model with OpenRouter API
llm = ChatOpenAI(
    base_url="https://openrouter.ai/api/v1",
    api_key=api_key,
    model="google/gemini-2.0-flash-lite-preview-02-05:free", # Reliable free model for tool-calling
    temperature=0,
    default_headers={
        "HTTP-Referer": "http://localhost:3000",
        "X-Title": "42 Berlin AI Workshop",
    }
)

# 4. Compile ReAct Graph with Checkpointer Memory
memory = MemorySaver()
agent = create_react_agent(
    model=llm,
    tools=tools,
    checkpointer=memory,
    prompt="You are a helpful AI assistant with access to local tools. Always verify computations and system details using your tools before answering."
)

# 5. Interactive Chat REPL Loop
def run_interactive_session():
    config = {"configurable": {"thread_id": "session_42_berlin"}}
    print("=" * 60)
    print("🤖 Agent Ready! (Connected to OpenRouter Free Tier)")
    print("Type your message, or type 'exit' / 'q' to quit.")
    print("=" * 60)

    while True:
        try:
            user_input = input("\nYou > ").strip()
            if user_input.lower() in ("exit", "quit", "q"):
                print("👋 Exiting workshop session...")
                break
            if not user_input:
                continue

            print("\n⚙️ Processing (Streaming Graph Steps)...")
            # Stream and inspect intermediate message steps
            for event in agent.stream(
                {"messages": [("user", user_input)]},
                config=config,
                stream_mode="values"
            ):
                latest = event["messages"][-1]
                # Only print new agent responses and tool executions
                if latest.type in ("ai", "tool") and latest.content != user_input:
                    latest.pretty_print()

        except KeyboardInterrupt:
            print("\nSession stopped.")
            break
        except Exception as err:
            print(f"⚠️ Error: {err}")

if __name__ == "__main__":
    run_interactive_session()

Part 4: Challenges - Hacking Phase Guide

Here is the complete Hacking Phase Guide with the 4 progressive challenges, exact solution code, and expected behavior.

Challenge 1: The Local File Explorer (Context Selection & Read Truncation)

Goal & Engineering Concept: Give the agent the ability to inspect the local file system. Emphasize why dumping entire large files directly into the context window triggers context rot and degrades reasoning. We mitigate this by reading only a truncated slice (e.g., first 500 characters).

Solution Code to Add to agent.py:

@tool
def list_directory(path: str = ".") -> str:
    """Lists files and folders in a given directory path."""
    try:
        items = os.listdir(path)
        return "\n".join(items) if items else "Directory is empty."
    except Exception as e:
        return f"Error listing directory: {e}"

@tool
def read_file_preview(filepath: str, max_chars: int = 500) -> str:
    """Reads the first N characters of a text file to prevent context window overload."""
    try:
        with open(filepath, "r", encoding="utf-8") as f:
            content = f.read(max_chars)
        return f"--- Content of {filepath} (first {max_chars} chars) ---\n{content}"
    except Exception as e:
        return f"Error reading file: {e}"

# Update tool registry:
tools = [calculate, get_system_info, list_directory, read_file_preview]

Test Query & Expected Output: You > List files in the current folder, find agent.py, and give me a brief summary of its first few lines.

Expected Behavior: 1. The agent calls list_directory("."). 2. The agent observes agent.py in the returned file list. 3. The agent calls read_file_preview("agent.py", max_chars=500). 4. The agent summarizes the imports and header setup.

Challenge 2: The External Scratchpad (The "Write" Strategy & Side Effects)

Goal & Engineering Concept: In Level 3 AI Engineering, tools start read-only before granting mutation/destructive access. This implements the Write context strategy: giving the agent a way to save notes to a persistent disk scratchpad rather than cluttering its working memory.

Solution Code to Add to agent.py:

@tool
def save_scratchpad_note(filename: str, content: str) -> str:
    """Writes or appends an important summary or finding to an external text file."""
    try:
        # Enforce writing to a safe .txt file only
        if not filename.endswith(".txt"):
            filename += ".txt"
        with open(filename, "a", encoding="utf-8") as f:
            f.write(content + "\n")
        return f"Successfully saved note to {filename}."
    except Exception as e:
        return f"Error writing note: {e}"

# Update tool registry:
tools = [calculate, get_system_info, list_directory, read_file_preview, save_scratchpad_note]

Test Query & Expected Output: You > Calculate 9999 * 42, write the result and a note saying 'Batch Complete' into my_notes.txt.

Expected Behavior: 1. Agent invokes calculate("9999 * 42") -> receives 419958. 2. Agent invokes save_scratchpad_note("my_notes.txt", "Calculation: 419958 - Batch Complete"). 3. File my_notes.txt is created on the student's laptop. 4. Discussion Point: Highlight the security implications when agents are given write access versus read-only access without a human in the loop.

Challenge 3: Breaking the Loop (Infinite ReAct Cycles & Failure Handling)

Goal & Engineering Concept: Demonstrate how the ReAct loop breaks down when tool outputs provide ambiguous errors. Non-deterministic models will attempt to re-prompt and hallucinate parameter adjustments, burning token limits.

Solution Code to Add to agent.py:

@tool
def flaky_network_fetch(endpoint: str) -> str:
    """Simulates an unreliable external API that always fails with an ambiguous error."""
    return "HTTP 500: Internal Server Error. Syntax rejected, try another format."

# Update tool registry:
tools = [calculate, get_system_info, flaky_network_fetch]

Test Query & Expected Output: You > Fetch data from endpoint 'user_profile_data' and extract the username.

Expected Behavior: 1. The agent calls flaky_network_fetch(endpoint="user_profile_data"). 2. It receives "HTTP 500: Internal Server Error...". 3. Instead of exiting immediately, the model enters a retry loop, altering the payload (e.g., flaky_network_fetch(endpoint="/api/v1/user_profile_data")). 4. Students will observe the console executing multiple consecutive tool turns until context builds up or it hits recursion limits.

Challenge 4: Build a Deterministic Eval Harness (Testing over Vibes)

Goal & Engineering Concept: Level 3/4 Agentic Engineering requires moving from "eval by vibes" to an automated testing harness. Instead of interactive terminal chatting, create a standalone test script eval_agent.py that evaluates the agent against verifiable criteria using plain code assertions and token logging.

New File: eval_agent.py Create eval_agent.py in the same directory:

import time
from agent import agent

# Define benchmark tasks with deterministic ground truth assertions
EVAL_SUITE = [
    {
        "id": "eval_math",
        "input": "Calculate 1024 * 64 exactly.",
        "expected_tool": "calculate",
        "expected_substring": "65536"
    },
    {
        "id": "eval_system",
        "input": "What OS am I running?",
        "expected_tool": "get_system_info",
        "expected_substring": "Darwin"  # Or "Windows" / "Linux" depending on the laptop
    },
    {
        "id": "eval_pure_reasoning",
        "input": "What is the capital of France? Answer in one word.",
        "expected_tool": None,  # Should NOT invoke tools
        "expected_substring": "Paris"
    }
]

def run_evals():
    print("================ RUNNING AGENT EVALUATION SUITE ================")
    passed = 0

    for test in EVAL_SUITE:
        print(f"\n[Test ID]: {test['id']}")
        print(f" Query: {test['input']}")

        tools_called = []
        final_answer = ""
        config = {"configurable": {"thread_id": f"eval_{test['id']}_{time.time()}"}}

        # Execute agent stream
        for event in agent.stream(
            {"messages": [("user", test["input"])]}, 
            config=config, 
            stream_mode="values"
        ):
            msg = event["messages"][-1]
            if msg.type == "ai" and msg.tool_calls:
                for call in msg.tool_calls:
                    tools_called.append(call["name"])
            elif msg.type == "ai" and not msg.tool_calls:
                final_answer = msg.content

        # 1. Deterministic Tool Assertion
        tool_passed = True
        if test["expected_tool"]:
            tool_passed = test["expected_tool"] in tools_called
        else:
            tool_passed = len(tools_called) == 0

        # 2. Output Fact Assertion
        content_passed = test["expected_substring"].lower() in final_answer.lower()

        test_success = tool_passed and content_passed
        if test_success:
            passed += 1
            print(f" -> Result: PASS ✅ (Tools: {tools_called})")
        else:
            print(f" -> Result: FAIL ❌ (Tools: {tools_called}, Expected Substring: '{test['expected_substring']}')")
            print(f"    Agent Output: {final_answer}")

    success_rate = (passed / len(EVAL_SUITE)) * 100
    print("\n================ EVALUATION SUMMARY ================")
    print(f"Total Passed: {passed}/{len(EVAL_SUITE)} ({success_rate:.1f}%)")

if __name__ == "__main__":
    run_evals()
